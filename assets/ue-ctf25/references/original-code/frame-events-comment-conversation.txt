// * 关于事件 *
// 为了使开发更加容易, Frame Events 中只有兼容选项，初始化以及物品库
// 大部分事件在对象的 Behavior 中, 以便日后随时使用全局对象更改
//
// 开发过程中，应特别注意暂停条件
// 对于 Group.Instance，由变量 1000 <> -1 给出
// 对于其他对象，由 "Pause" 对象的 "Pause" off 给出
//
// 特别地, Frame Event 的功能被对象 "Process Start Event" 以及 "Process End Event" 取代，它们分别在每一帧最开始和最后执行事件
// 为兼容各引擎，全局变量先读取入 "Globalvar"，之后均由该物件完成操作
// 如需插入其他项目中，记得复制全局事件，并修改 "Event order" 为：
// Frame events, Behaviors, Global events
//
// 警告：不要删除 "Process Start Event" 对象，否则可能对事件顺序造成不可逆影响

// * 关于 Foreach 函数 *
// Instance 组含有 Foreach 函数，这是一类非常特殊的事件
// 其原理在于 Foreach 为绿色条件优先执行事件，即调即用，作为函数有时候很方便
//
// 但 Foreach 本身并不是拿来干这个的，这本身是非常浪费性能的
// 所以这类事件在开发过程中应该尽可能地避免使用，在实在没办法的时候再调用
