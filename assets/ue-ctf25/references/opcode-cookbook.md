# 事件记录模板与 opcode 速查（全部来自已验证导出）

规则：**先找语义相同的现成记录，整段复制，只改已知偏移**；不要凭猜测拼新 opcode。
每条模板都标了来源，改动后用 `verify_events.py` + `ctf_events.py describe` 复核。

## 1. 条件模板

### 标志位

| 语义 | type,op | 头（条件 16B，动作 14B） | 参数 |
|---|---|---|---|
| Flag N is on | `(2,-25)` | `3600 0200 e7ff <obj> 0000 2000 01 00 0000` | t22，34B：`0000 ffff 0000 0a00 <N u32> 0000…`；N 在 body+8 |
| Flag N is off | `(2,-24)` | `3600 0200 e8ff <obj> 0000 2000 01 00 0000` | 同上 |
| Set Flag N on（动作） | `(2,35)` | `3400 0200 2300 <obj> 0000 0000 01 00` | t22，34B，同上 |

来源：`process-start.json` #2 C0（on，flag 0）、`lavaball-track-init.json` #0 C0（off，flag 20）、
同文件 A12（第 13 个动作；set on，flag 20）。事件号及 C/A 序号均从 0 开始。

注意：标志位在 Fusion 里可命名（UE 的 `Pause`、`受伤`），但**事件里只存编号**，
名字只在对象属性里。存储的是 0～31。

### 数值比较

| 语义 | type,op | 参数 |
|---|---|---|
| Alterable Value(N) of X 比较 值 | `(2,-27)` | P0 = 目标下标（t50 6B：`<u32 N> 0000`，或 t53 16B：`0000 ffff 0000 0a00 <u32 N> 0000 0000`）；P1 = t23 比较表达式 |
| 比较表达式 t23 | — | 16B：`<u16 op> ffff 0000 0a00 <u32 值> 0000 0000`；op：0 `=`，1 `<>`，2 `<=`，3 `<`，4 `>=` |

来源：`mario-movement.json` #161（1000 `<>` -1、100 `<>` -1、AQ `=` 0）、#160（AN `=` 1）。

### 其他常用条件

| 语义 | 记录 |
|---|---|
| Always | `(-1,-1)` = `10 00 ff ff ff ff 00 00 00 00 20 00 00 00 00 00` |
| NOT | `(-1,-25)` = `10 00 ff ff e7 ff 00 00 00 00 00 00 00 00 00 00` |
| On loop "name" | `(-1,-16)` + t45（UTF-16 循环名） |
| On each one of X, loop "name" | `(2,-41)` + t45 |
| Repeat while Player 1 Pressed fire 1 | `(-7,-6)` 头 `18 00 f9 ff fa ff 00 00 00 00 20 00 01 00 00 00` + t17 `08 00 11 00 10 00 00 00` |
| Player 1 Pressed fire 1（触发一次） | `(-7,-4)` 头 `18 00 f9 ff fc ff 00 00 00 00 00 00 01 00 00 00` + 同 t17 |
| X is overlapping Y | `(2,-4)` + t1 `0c 00 01 00 00 00 <Y id u16> 02 00 00 00`（总长 12B；Y id 在 body 偏移 2，即参数头起点偏移 6） |

键位掩码（t17 u32）：fire 1 = `0x10`，fire 2 = `0x20`，方向 = 1/2/4/8。
取反既可用条件头偏移 10 的 u16 的 `0x0100` 位，也可用独立 `(-1,-25)`，见
[event-binary-format](event-binary-format.md) §2.2。

## 2. 动作模板

| 语义 | type,op | 参数 |
|---|---|---|
| Set Alterable Value(N) to 表达式 | `(2,31)` | P0 下标（t50/t53 同上）；P1 t22 表达式 |
| Add 表达式 to Alterable Value(N) | `(2,32)` | 同上 |
| Play sample "name" | `(-2,0)` | t6：4B 0 + UTF-16LE 名 + 0 填充 |

来源：`mario-movement.json` #166/#167（AM=0、AN=1、101=跳跃）、#174（音效）。

## 3. 表达式指纹（防拿错分支）

表达式不可手改，但可以用“指纹”确认拿对了：

| 动作 | 必须包含 | 必须不包含 |
|---|---|---|
| 地面跳跃：`101 = 0 - 跳跃初速度 - AltValN(103)` | `0a` 速度字节 + `67 00 00 00` | `69 00 00 00` |
| 游泳：`… 游泳初速度 … 105` | `0b` + `69 00 00 00` | `67 00 00 00` |
| 跳出水（空中）：`… 105` | `0c` + `69 00 00 00` | `67 00 00 00` |
| 跳出水（着地）：`… 105` | `0d` + `69 00 00 00` | `67 00 00 00` |

这四个动作所在事件几乎长得一样，**其中两条（#167 地面跳、#174 着地跳出水）都播 `mario_jump`**，
只按音效或“条件 100=0”挑会拿错。正确做法：
1. 看父事件是不是 `AM=1` + `100<>-1`；
2. 看该动作所在子事件的 overlap 条件取反位（条件头偏移 10 的 u16 含 `0x0100`，即偏移 11 的字节 bit0 为 1）；
3. 断言表达式里出现 `103`（`67`）且没有 `105`（`69`）。

## 4. Mario 变量下标

A～Z = 0～25；AA=26、AB=27……；常用：

| 名 | 下标 | 名 | 下标 |
|---|---|---|---|
| AL 碰撞动画记录 | 37 | AM 有效跳跃 | 38 |
| AN 连跳锁 | 39 | AO 落水 | 40 |
| AP 管道状态 | 41 | AQ 蹲下/卡墙 | 42 |
| AS 朝向 | 44 | AT 速度 | 45 |
| AU/AV 方向键记录 | 46/47 | AW 重力方向 | 48 |
| AX/AY 左右输入 | 49/50 | AZ 延迟操作 | 51 |

引擎保留：1000 初始化态、100 着地(=0)/空中(=1)、101 重力轴速度、
1002 碰撞类型、X/Y = 23/24。

## 5. 现成配方：被 Flag 0 门控的“空中再跳”

候选事件（单条顶层事件，不依赖 AM；仅通过本地字节及结构检查，插入位置和运行行为待 Fusion 验证）：

```
+ 无限跳: Flag 0 is on
+ Repeat while Player 1 Pressed fire 1
+ Alterable Value(1000) of Mario <> -1
+ Alterable Value(100) of Mario = 1
+ Alterable Value AQ of Mario = 0
+ Alterable Value AN of Mario = 0
+ Alterable Value AO of Mario = 0
    Mario : Set Alterable Value(101) to 0 - 跳跃初速度( "Mario" ) - AltValN( "Mario", 103 )
    Mario : Set Alterable Value AN to 1
    Sound : Play sample mario_jump
```

为什么这样写：
- 引擎自己的起跳在 `AM=1` 事件里，且 `AM` 每帧被按键事件清零；从别的对象/事件列表
  改 `AM` 可能因执行顺序失效。直接写 `101` 避开 AM 门控，但仍须检查与 `frame_start`
  及后续物理更新的时序，不能据此保证任意插入位置都有效。
- `AN=0` + 动作里 `AN=1` 复刻引擎的“一次按键一次跳”，避免按住连飞。
- `AO=0` 用于筛除落水状态；水中与入水当帧是否会和游泳分支叠加，仍需运行验证。
- 想“按住持续上升”就别加 `AN`，但那不是原版手感，需用户确认。

## 6. 新增对象的元数据

- 新 Active：`type=2`、类名 `Sprite`、`OIC0`（无图标负载）、`flags=0`（帧事件导出）
  或 `1`（该对象是本事件列表主体）。
- 需要引用限定符组时（如 `Group.Water`）：`type=3` + 组编号（Water=5），
  没有图标块。
- 对象 id 从 0 递增，事件里的 object 字段引用它；**id 不是数组下标**，但通常一致。
